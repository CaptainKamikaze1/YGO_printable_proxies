# YGO Printable Proxies

A Yu-Gi-Oh! proxy card generator: search cards, build a deck, import/export `.ydk` files, and print a ready-to-cut 3x3 grid (front and optionally mirrored card backs) on A4 paper.

**Live site:** https://captainkamikaze1.github.io/YGO_printable_proxies/

## Usage

Open the live site, or download `index.html` and open it directly in a browser (no installation, no build step).

## Sources

- Card data and images: [YGOPRODeck API](https://ygoprodeck.com/api-guide/)
- Card back artwork: [icycatelf (DeviantArt)](https://www.deviantart.com/stash/0cz210ardpx)
